# InfiniAct Homebrew Tap

Official Homebrew tap for [InfiniAct](https://www.infiniact.com) apps.

## Install

```bash
brew install infiniact/release/iaterm
```

Homebrew taps this repository automatically on first install. Upgrade with `brew upgrade --cask iaterm`.

| App | Command | Website |
|---|---|---|
| IATerm — terminal for the AI era | `brew install infiniact/release/iaterm` | https://www.iaterm.ai |

## Notes

- Installers are signed with Developer ID and notarized by Apple.
- If downloads from GitHub are slow in your region, get the DMG directly from https://www.iaterm.ai.
- Users of the previous tap `infiniact/iaterm` are migrated here automatically on `brew update`.

## 安装

```bash
brew install infiniact/release/iaterm
```

首次安装时 Homebrew 会自动添加本仓库，升级用 `brew upgrade --cask iaterm`。

- 安装包使用 Developer ID 签名并经过 Apple 公证。
- 如果 GitHub 下载较慢（如国内网络），请直接从 https://www.iaterm.ai 下载 DMG。
- 之前通过 `infiniact/iaterm` 安装的用户，执行 `brew update` 时会自动迁移到本仓库。
